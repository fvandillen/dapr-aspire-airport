# Demo Time setup

This folder contains a slides-first Demo Time setup for the session:

- `Dapr + Aspire: Distributed Systems Without the Headache`

## Files

- `01-dapr-aspire-session.yaml`: Act file (version 3) with 21 scenes in talk order.
- `slides/dapr-aspire-session.md`: Slide deck markdown (21 slides in one grouped file).

## How to run

1. Install the VS Code extension `eliostruyf.vscode-demo-time`.
2. Open the Demo Time view in VS Code.
3. Open `01-dapr-aspire-session.yaml` and run scenes in sequence.
4. Use presentation mode to advance through slides during the talk.

## Scope note

This setup currently covers the **presentation narrative and slide flow only**.
Live code demos for pub/sub, state, service-to-service, and workflows will be added
later as additional scenes/moves that interleave with the existing slide scenes.
